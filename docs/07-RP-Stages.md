# Ktits-Mod 0.1.0: поэтапная загрузка в RandomParadox

Мод: **Ktits-Mod**, версия **0.1.0** (имя в программу вводить без слэша на конце).
Общая инструкция по программе и путям: `06-RandomParadox-Guide.md`.

Этап заканчивается, когда мод с видимым изменением запускается в игре. Следующий этап начинается после сообщения «этап N готов».

Файлы этапов генерируются скриптом `tools/export_rp_inputs.py` из `03-Map-Sketch.svg` в `no_commit/temp/rp_input/stage_NN/` (в git не попадают, получаются запуском скрипта: `python tools/export_rp_inputs.py N`).

Названия вкладок и кнопок программы взяты из видео по автоматическим субтитрам: сверять с самой программой [uncertain].

## Этап 1. Суша и высоты

**Файлы** (`no_commit/temp/rp_input/stage_01/`):
- `land.png`: 4608 × 2816, RGB, 8 цветов;
- `land_preview.png`: уменьшенная копия для просмотра;
- `colors.txt`: список цветов.

**Цвета.** Взяты из справки вкладки Land Input: эти цвета программа понимает сама, ручная разметка не нужна (проверить, что нет «UNCLASSIFIED»). Замечено при проверке: программа называет (0,0,255) `deepOcean`, а (0,0,128) `ocean`, обратно справке; цвет 255 255 255 она не распознаёт, поэтому в файле он не используется.

| Цвет (R G B) | Тип | Где на нашей карте |
|---|---|---|
| 0 0 255 | deepOcean | открытый океан |
| 0 0 128 | ocean | прибрежная вода |
| 0 80 140 | lake | Каспийская Дырка, озеро Челяба |
| 128 128 128 | plains | всё остальное (леса, болота, пустыня уточняются на этапе 2) |
| 150 180 150 | lowhills | широкая кайма предгорий |
| 140 160 150 | hills | предгорья хребтов |
| 220 220 220 | mountains | хребты, Айдалия, горы Северной Ассамблеи, горы у Ставки Казуала |
| 240 240 240 | peaks | Нагорье Шамбалы |

**Что делать в программе** (подтверждено справкой вкладки Land Input на скриншоте):
1. Вкладка **Configure**: имя мода `Ktits-Mod`, пути (см. `06`), размер карты 4608 × 2816 [uncertain: где поле размера].
2. Вкладка **Land Tabs → Land Input**: выбрать режим **Landform**.
3. **Перетащить `land.png` мышью в окно программы.** Появится список «Currently labeled as…» для найденных цветов.
4. Все цвета, помеченные UNCLASSIFIED, разметить вручную (кнопка «Select type for …» и тип из таблицы выше). Если у цвета Apply красный, его нужно нажать.
5. Нажать **Analyse Input** (только после разметки).
6. Вкладка **Heightmap** → «Generate Complete Heightmap from new seed» (зелёная кнопка внизу); на вкладке Land Input или Heightmap убедиться, что результат построен по нашей картинке, а не случайный.
7. Остальные вкладки оставить по умолчанию, как в пробном прогоне; **Finalise** → экспорт полного мода.

**Проверка в игре (что должно быть видно):**
- В лаунчере включить `Ktits-Mod`, остальные моды выключить.
- Новая игра → любая страна → режим карты «рельеф» (terrain map mode).
- Форма материка и островов совпадает со схемой `03-Map-Sketch.svg`: длинный залив Синего моря на северо-западе, два больших озера (Каспийская Дырка и маленькое Челябы), острова Бриттана и юго-восточные острова.
- Узкие горные полосы на местах хребтов; крутые пики в одной точке на востоке (Нагорье Шамбалы).

**Береговая линия.** В `tools/export_rp_inputs.py` берега не прямые линии схемы: общий сдвиг карты фрактальным шумом (до ~70 px) плюс размытие и шум у побережья; озёра, внутренние моря (Синее, Кряхтское, пролив) и проливы между островами сохранены (пролив между Кряхтским и Средним морями шире, чем на схеме). Параметры в начале функции `stage1()` и поля `DX/DY` вверху файла.

Источники: справка вкладок Climate Input и Climate Generation (`no_commit/temp/rp_doc_summary.md`, разделы 4-5). Всё, что не подтверждено справкой, помечено [uncertain].

Решение: на этапе 2 только влажный холодный умеренный климат, болота отдельным этапом (6).

### 2.2. Порядок действий в программе

1. Climate Input: загрузить `climate.png`, разметить, Analyse.
2. Climate Generation (подвкладки): Temperature → Humidity → Rivers → Climate → Forests. Режим Climate: `Climate Input Mode` (по справке такой есть; по умолчанию Simulated Climate) [uncertain].
3. Rivers на этом этапе оставить автоматическими (наши реки грузятся на этапе 3; реки влияют на влажность, поэтому после этапа 3 климат перегенерировать).
4. Forests: сгенерировать от климата, плотность по зонам (borealDensity, temperateMixedDensity и т.д. из конфига) оставить по умолчанию; слишком густой лес ломает игру при приближении.
5. Параметры по необходимости: Base humidity / Base temperature, Fantasy Climate (включать, если климат из входного файла искажается широтой), Latitude high/low (задают, где «полюс» и «экватор»; у нас юг тропический, север холодный, значит экватор на юге, high = 2.0 на севере).
6. Сохранить результат (промежуточные карты в `Maps/climate/` рядом с exe) на случай правки руками.

### 2.3. Леса (вручную по лору)

Леса по всей карте: Северная Ассамблея, СССР, Федерация Депутатов, Тямовский рейх, Соевая Республика, Зеленодольск (Центр), Королевство Муси, леса Магнолии. Формат карты лесов для загрузки в справке не описан [uncertain], поэтому сначала даём программе сгенерировать леса от климата, смотрим результат в `Maps/`, затем при необходимости правим лес картинкой и грузим обратно.

### 2.4. Что проверить в игре

- Режимы карты «рельеф», «климат/сезоны» (если есть): пустыня Магнолии, снег Ледышки и вершин, джунгли юга Фигарии, леса севера.
- Зима: север должен покрываться снегом, юг нет (сезонные карты создаёт программа, `Maps/seasons`).
- В логе нет ошибок о климатических картах.

### 2.5. Риски

- Цвета в PDF и справке расходятся: ориентироваться на тот список, который программа показывает на экране (как с ocean/deepOcean на этапе 1).
- Климат из входной картинки смешивается с симуляцией: резкие границы между зонами могут размыться, это нормально.
- Реки на этапе 2 случайные: после этапа 3 климат и леса нужно перегенерировать.
- Пустыня и тропики на одном материке с холодным севером: широтный градиент может мешать; если так, включить Fantasy Climate.

## Этап 3. Реки

**Файл:** `no_commit/temp/rp_input/stage_03/rivers.png` (4608 × 2816, как `land.png`), запуск `python tools/export_rp_inputs.py 3`. Реки берутся из схемы `03-Map-Sketch.svg` (класс `river`) и из Джунгарика на юге Фигарии, обрезаются по береговой линии из этапа 1.

**Цвета** (справка вкладки Rivers; ручной разметки нет):

| Цвет (R,G,B) | Что |
|---|---|
| 255,255,255 | фон |
| 0,0,255 | русло, линия шириной 1 пиксель |
| 0,255,0 | начало реки (обязательно у каждой реки) |
| 255,100,0 | конец реки (устье или обрез по берегу) |

Притоки (0,128,0) не используются: на схеме реки отдельные линии, притоки не заданы.

**Что делать в программе** (по скриншотам: у вкладки River нет кнопки загрузки, только «River Multiplier», «Generate River Map» и «Generate River Map (new seed)»; в справке вкладки: «Loading of rivers is unstable»):
1. Climate Tabs → подвкладка **River…** (должна быть открыта).
2. Перетащить `rivers.png` мышью в окно программы, как делалось с `land.png` и `climate.png`. Загрузка прошла, если в нижнем логе появились строки `Colour Mapping: 0;255;0 -> 0;255;0`, `255;100;0 -> 255;100;0` и т.п. и `Writing rivers.png`.
3. НЕ нажимать «Generate River Map»: она заменит наши реки случайными.
4. Проверить результат: файл `Maps/climate/rivers.png` рядом с exe (наши реки должны быть на месте).
5. Вернуться на Climate Input → «Generate from labeled climate» (климат учтёт реки).

**Допущения:**
- Направление реки = порядок точек в пути SVG (начало первой точкой, конец последней). Для Казуахии и Джунгарика это верно, для остальных рек не проверялось.
- Если река пересекает озеро или залив, она режется на участки, у каждого свои начало и конец.
- Реки в SVG короткие (на схеме), поэтому их длина в игре небольшая; случайные реки программа может добавить сама (множитель riverFactor).

**Проверка:** в лаунчере включить мод, в игре режим «рельеф»: реки видны как голубые линии от гор к морю.

**Готово, когда:** программа приняла `rivers.png` без ошибок, реки видны на карте мира, мод запускается.
