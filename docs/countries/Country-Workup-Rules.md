# Правила проработки страны

Порядок и требования к проработке отдельной страны (своё древо фокусов, механики, решения). Составлено по опыту Казуалии: образец — `mechanics/Kazualia.md`, `focuses/Kazualia-Focus-Tree.md`, скрипты `tools/make_kazualia.py`, `tools/make_kazualia_outer.py`. Общие правила проекта — `CLAUDE.md`; шаблон описания страны — `countries/Country-Template.md`.

## 1. Этапы

| № | Этап | Результат |
|---|---|---|
| 1 | Сбор лора | выписка из `lore/Contries-Description.md` в начало документа механик; набросок автора |
| 2 | Документ механик | `docs/mechanics/<Страна>.md` |
| 3 | Документ древа фокусов | `docs/focuses/<Страна>-Focus-Tree.md` |
| 4 | Вопросы автору | раздел «Открытые вопросы»; работа дальше — только после ответов на спорное |
| 5 | Перенос придуманного | `lore/Invented-Lore.md` (сжато, ссылками) |
| 6 | Портреты | строки в `image_generator/images-list.md` (таблица «Портреты лидеров») |
| 7 | В игру | только после слова автора «в игру»; скрипт `tools/make_<страна>.py` + шаг в `post_export.py` |
| 7а | Правило игры путей | правило `ktits_<tag>_paths` и локализация (если путей несколько), строка в `global_mechanics/Game-Rules.md`; в игре не сделано |
| 8 | Проверки | проверки в `check_mod.py`, отладочный журнал (`global_mechanics/Debug-Log.md`) |
| 9 | Прогон | автор играет / `observe`; разбор `error.log` и отчёта журнала; правки |

**Перед этапом 1** сгенерировать и записать в документ механик стартовые популярности идеологий страны (Казуальность, Демократия, Нейтралитет, Коммунизм, Фашизм; сумма 100 %). Значения выводить из лора (строй, правитель, предыстория); придуманное явно пометить как придуманное и отдать автору на подтверждение. Пример: у Казуалии Казуальность 90 %, Демократия 5 %, Нейтралитет 5 %.

## 2. Документ механик (`docs/mechanics/<Страна>.md`)
Разделы по образцу Казуалии:
- **Статус** (только описание / реализовано [uncertain: в игре не проверено]).
- **Кратко о стране**: тег, штаты, население, образование, правитель, столица, соседи, выделяемые части `Kxx`.
- **Механики** — по разделу на каждую. В каждом:
  - правило автора отдельно от придуманного: «(правило автора)», «Предложение (придумано)», «Детали (придуманы, подтверждены автором)»;
  - переменные (`ktits_<код>_<имя>`), диапазон, старт, ежемесячное изменение;
  - **шкала** в своей категории решений, когда уместно (как у образования и Казуальности);
  - решения — таблицей: название, описание (лор), эффект, цена, перезарядка;
  - художественное описание механики.
- **Стартовый ивент** — название, текст, кнопка (обязателен для проработанной страны).
- **Правители** — по идеологиям; описание внешности для портрета.
- **Связи** с глобальными механиками и другими странами.
- **Открытые вопросы**; решённые — зачёркнуть и пометить «решено автором».
- **Реализация** (после переноса в игру): что сделано, что нет и почему, [uncertain].

## 3. Документ древа фокусов
- Таблица «Состав древа»: ветка, откуда (лор / правило автора / придумано), кому доступна.
- На каждую ветку: схема mermaid `flowchart TD` (узел = фокус, стрелка = предпосылка, взаимоисключающие — пунктир с подписью) и таблица: Фокус, Дни, Описание, Эффект, Условие.
- **Обязательные ветки:** политическая (выбор пути/идеологии), экономика, армия (флот и авиация — при выходе к морю / по смыслу); ветки уникальных механик страны.
- **У каждого фокуса — реальный эффект** (не только флаг). Образцы эффектов — ванильные фокусы.
- Стандартные ветки общего древа («Казуальность», «Политический курс») — явно указать, доступны ли стране.

## 3а. Что решить ещё на этапе md
Всё ниже у Казуалии всплыло только после прогонов в игре и потребовало переделок. Для новой страны эти пункты закрываются в документах **до** переноса в игру — ответом автора или явным предложением «(придумано)».

| Вопрос | Что записать в md |
|---|---|
| Пути развития | какие пути взаимоисключающие; нет ли внутри пути разных стратегий, которые надо разделить на ветки (у Казуалии «Нейтралитет» и «Великая Казуалия») |
| Развилки | после каждой развилки (фокус, чьи дети — взаимоисключающие варианты) каждая альтернатива продолжается минимум двумя фокусами; развилка не должна вести в единственный тупиковый фокус |
| Правило игры для путей (в игре не сделано) | **обязательно** для страны с несколькими путями: правило `ktits_<tag>_paths` в расширенных настройках, опции по образцу ванильных (`SOV_ai_behavior`): «ИИ по весам» и по одной опции на каждый путь страны, только для ИИ; описание и дефолты — `global_mechanics/Game-Rules.md` |
| Ветки по путям | какая ветка на каком пути доступна и что закрывает отказ от неё (изгнание бриттов закрывает ветку) |
| Эффект каждого фокуса | конкретный эффект числом; «открывает решения» — только вместе с ощутимым бонусом |
| ИИ | порядок веток (политика первой), выбор пути с весами, когда ИИ отказывается от невыгодных духов, кого атакует первым (слабые соседи) |
| Решения | группы решений и их цвета; какие видимы всегда; что игрок узнаёт после решения (событие или новость с перечнем полученного) |
| Шкалы | у каждой механики со шкалой — где видна, старт, ежемесячное изменение, потолок за год (числа сверить: шкала не должна упираться в 0/100 за год) |
| Видимость влияния | если механика действует на другие страны — где игрок видит их состояние и изменение |
| Баланс | порядок величин бонусов и штрафов (исследования, производство, Вера/ресурс) относительно ванили; чтобы штраф ощущался и не ломал игру |
| Стартовые условия | законы (экономика, призыв), ядра, марионетки, альянсы, правитель по каждой идеологии, стартовые популярности идеологий (сумма 100 %) |
| Территории | что реализуемо: модификаторы атаки и защиты на штат не вешаются — только через `army_core_*` / `army_non_core_*` и модификаторы штата (`enemy_attrition` и др.); железные дороги и снабжение |
| Глобальные механики | как страна вписывается в альянсы (кто может основать и вступить), Казуальность, образование; войны только через обоснование цели или свои механики |
| Отделяемые страны | размер буферов и выделяемых частей (список штатов), их правители и стартовая идеология |
| Провал и успех | что происходит при неудаче механики (проигранное восстание → «Отрезвление» и шкала 0) |
| Названия и тексты | художественное описание у каждого элемента, стартовый ивент, правители и портреты — сразу |

## 4. Перенос в игру
- Отдельный скрипт `tools/make_<страна>.py` по образцу `make_kazualia.py`: генерирует все файлы страны, идемпотентен; шаг в `post_export.py` в нужном месте (после механик, от которых зависит; `make_icons.py` всегда последним).
- **Локализация** ru и en, UTF-8 с BOM. У каждого духа, решения, события, фокуса — художественное описание (`_desc`), не перечень модификаторов.
- **Решения**:
  - базовые решения категории видимы всегда, недоступные — серые: условия в `available`, перезарядка — флагом, а не `days_re_enable`;
  - целевые решения — широкий список целей в `target_trigger`, условия в `available`;
  - группы решений различать иконкой и цветным префиксом без квадратных скобок: `§RАрмия:§!`, `§YСнаряжение:§!`, `§GЭкономика:§!`, `§BНаука:§!`, `§OПолитика:§!` (кодов `§P`, `§M` в игре нет);
  - если решение даёт снаряжение или «плюшку» — сообщить игроку событием или новостью, что именно получено.
- **Шкалы** — scripted_gui на 20 сегментов (как `ktits_kin_ui`), значение крупно и цветом в первой строке описания категории.
- **Древо фокусов**:
  - ИИ: `ai_will_do` — политическая ветка и выбор пути намного выше военной (корень ~1000, пути 60–300, армия ~3);
  - раскладка компактная, без наложений (словарь `LAYOUT`, проверка в check_mod); `continuous_focus_position` так, чтобы панель непрерывных фокусов не закрывала древо;
  - фокусы с «опасными» эффектами (стать марионеткой, вступить в альянс) — с проверкой правил глобальных механик (альянсы: `global_mechanics/Alliances.md`).
- **Правители**: персонаж в `common/characters` + `recruit_character` в history; идеология лидера — в группе `ruling_party` (иначе игра сгенерирует случайного правителя с силуэтом). Портреты: исходники в `gfx_src/portraits/`, копирование шагом сборки.
- **Иконки**: исходники в `gfx_src/ideas/`, подключение через `make_icons.py`; файлы `.gfx` — UTF-8 **без** BOM.
- **Стартовые законы, ядра, марионетки** — в history страны через скрипт, не руками.
- **ИИ механик**: веса решений по условиям (не брать решения, ведущие шкалу в потолок; не держать невыгодные духи); агрессия — сначала на слабых соседей.

## 5. Проверки
- В `check_mod.py` — проверка на каждую механику: файлы созданы, ключи и локализация есть, у фокусов есть эффекты, нет наложений, правитель recruited, нет BOM в `.gfx`, нет `[` с кириллицей в локализации.
- Отладочный журнал: строки `[KTITS][<раздел>]` на ежемесячные значения шкал, фокусы, решения, события, войны (`global_mechanics/Debug-Log.md`).
- Ключи эффектов, триггеров и модификаторов — только сверенные с `documentation/*.md` и ванильными файлами; непроверенное — [uncertain].

## 6. Известные ловушки
| Ловушка | Решение |
|---|---|
| `.gfx` с BOM — спрайты не грузятся («?» вместо иконок) | писать `.gfx` в UTF-8 без BOM |
| `[Текст]` в локализации — пропадает (скриптовое выражение) | не использовать квадратные скобки в тексте |
| архетип снаряжения в `add_equipment_to_stockpile` — ошибка | конкретные `*_equipment_1` |
| `divide_variable` на temp-переменной не работает | `divide_temp_variable` |
| `days_re_enable` — решение пропадает на перезарядке | перезарядка флагом в `available` |
| пересборка мода при открытой игре (отладка) — горячая перезагрузка и вылет | закрывать игру на время сборки |
| остатки RandomParadox (`events/rpx_*`) — войны без цели, лишние события | нейтрализовать в `fix_vanilla_leftovers.py` |
| ванильные шаблоны фракций видимы всем | скрывать все, кроме своего (`make_alliances.py`) |
| координаты провинций устаревают после переэкспорта карты | брать провинцию по данным штата (очки победы), не по пикселю |
| два history-файла на один тег после перенумерации | чистка по полному имени файла (`make_splits.py`) |
