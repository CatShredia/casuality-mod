# Паспорт страны (вход для одного промпта)

Заполненный паспорт + фраза «проработай <тег> по паспорту `docs/countries/passports/<tag>.md`, в игру» = весь конвейер (этапы 1–8 из `Country-Workup-Rules.md`) без уточнений. Образец заполнения — Казуалия (`mechanics/Kazualia.md`). Лор страны берётся из `lore/Contries-Description.md`; паспорт его не дублирует, а добавляет решения автора. Пустое поле = «придумай и перечисли в ответе»; помечено `?` = «спроси».

## 0. Промпт (копировать)
```
Проработай страну <тег> по паспорту docs/countries/passports/<tag>.md.
Порядок: md (механики, древо, Invented-Lore) -> в игру (tools/make_<страна>.py, шаг в post_export) -> пересборка -> check_mod.
Придуманное перечисли в ответе и в Invented-Lore.md. Не коммитить.
```

## 1. Паспорт (поля)

### 1.1 Основа
| Поле | Образец (Казуалия) |
|---|---|
| Тег, название (ru/en), прилагательное | SCU, Казуалия |
| Штаты, население, образованность | список штатов, млн, уровень |
| Правитель по идеологиям (имя, титул, внешность для портрета) | Сабиров (коммунизм), Лорд Бульдог Казуал (демократия) |
| Стартовые популярности (сумма 100 %) | 90/5/5/0/0; пути смены должны оставаться достижимыми |
| Стартовые законы, ядра, марионетки, альянсы | |
| Соседи и влияние других стран | Бритты, СССР |
| Особый эффект территории / духи | Дурманище |
| Технологии | Казуалия: «минимум» (только пехотное оружие); СССР: набор ванильной истории Советского Союза |
| Генералы | 20 на страну (2 фельдмаршала + 18 командиров корпусов), 4 портрета на страну; `countries/Generals.md` |

### 1.2 Механики (по блоку на каждую)
Название · переменная `ktits_<тег>_<имя>` · шкала (старт, диапазон, ежемесячное изменение, потолок за год) · решения (группа и цвет, цена, перезарядка, цель) · что видит игрок · провал и успех · связь с Казуальностью.

### 1.3 Пути развития
| Поле | Образец |
|---|---|
| Список путей, взаимоисключающие | сохранение / Великая Казуалия / нейтралитет / реформизм / коммунизм / демократия |
| Подпути и развилки (каждая альтернатива ≥ 2 фокуса) | СССР: сотрудничество 3 исхода, казуальный коммунизм |
| Условие входа | смена идеологии только при популярности ≥ 50 %; перед ней фокусы усиления + решение на популярность |
| Откат / гражданская война | при победе казуалов реформы откатываются, открывается казуальная ветка |
| Правило игры `ktits_<тег>_paths` | опции: DEFAULT + по одной на путь |

### 1.4 Древо фокусов
Ветки: политика (первая), экономика, образование, армия (+флот/авиация по выходу к морю), ветки уникальных механик, совместные (модернизация). У каждого фокуса: дни, эффект числом, лорное описание. Общее древо «Казуальность»/«Политический курс» — доступно или нет. Раскладка: компактно, без наложений.

### 1.5 События и тексты
Стартовый ивент (название, художественный текст, кнопка), события путей и провалов, новости. Описание у каждого духа, решения, события, фокуса (не перечень модификаторов).

### 1.6 Выделяемые части
`Kxx`: список штатов, правитель, стартовая идеология.

### 1.7 Картинки и ИИ
Портреты (описание), флаги по идеологиям, иконки (дух, решение, фокус 94x76, событие 210x120, категория 504x120): строки в `image_generator/images-list.md`. ИИ: веса путей, порядок веток, кого атакует.

## 2. Что делает конвейер (по паспорту)
| Шаг | Результат |
|---|---|
| 1 | `docs/mechanics/<Страна>.md`: статус, механики, ивент, правители, открытые вопросы |
| 2 | `docs/focuses/<Страна>-Focus-Tree.md`: состав, mermaid, таблицы |
| 3 | `Invented-Lore.md`, `Game-Rules.md`, `Guide.md` |
| 4 | `tools/make_<страна>.py` (+ `_outer` при большом объёме), шаг в `post_export.py`, правитель в `make_rulers.py`, правило игры |
| 5 | проверки в `check_mod.py`, журнал `Debug-Log.md` |
| 6 | пересборка, итог: проверки, что не проверено в игре [uncertain], список придуманного |

Субагенты (если просят): зоны без пересечений — механики/скрипт, древо фокусов, документы, картинки; пересборка только главным.

## 3. Чек-лист готовности паспорта
- [ ] 1.1 заполнено, популярности = 100 %
- [ ] ≥ 1 путь; развилки с ≥ 2 фокусами после каждой
- [ ] у каждой шкалы старт, шаг и потолок
- [ ] есть правило смены идеологии (≥ 50 %, усиление, решения)
- [ ] описан стартовый ивент и правители
- [ ] картинки перечислены
- незаполненное: оставить пустым или `?`, не `-`
