# Выделяемые государства больших стран

Страны с числом штатов больше 15. Все названия и разбиение — ПРИДУМАНЫ (не лор). Части получены автоматически (рост областей по соседству штатов, родитель сохраняет часть со столицей). Скриптовое выделение (`ktits_release_Kxx`) работает только у страны с флагом падения в Казуальность (триггер `ktits_splits_enabled`). Выделение через меню «Оккупация» разрешено, пока шкала Казуальности страны не больше 50 (см. `global_mechanics/Casuality-Mechanic.md`, «Выделение стран и Казуальность»). Части освобождаются автоматически при падении страны в Казуальность (`ktits_split_on_fall`, см. `global_mechanics/Casuality-Mechanic.md`), новые страны становятся марионетками Казуалии. Статус выделенных стран не определён.
