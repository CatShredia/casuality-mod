# Правила игры (расширенные настройки)

**Статус: в игре, не проверено** (правило `ktits_kaz_paths` в `make_casuality.py`). Всё предложенное ниже придумано, нужно подтверждение автора (см. «Открытые вопросы»).

## 1. Что уже есть в моде
- Ванильные общие правила оставлены, правила несуществующих стран убраны (`tools/make_game_rules.py`, `map/build/Map-Finish-Plan.md`).
- Правило мода `ktits_global_casuality` (группа `RULE_GROUP_AI_BEHAVIOR`, файл `common/game_rules/ktits_casuality_rules.txt`, `tools/make_casuality.py`): стартовый шанс и множитель курса «Сближение» у малой страны ИИ. Ключи локализации: `KTITS_RULE_<ПРАВИЛО>` (имя), `KTITS_RULE_OPT_<ОПЦИЯ>` и `..._DESC`. Опции кроме `DEFAULT` отключают достижения.

## 2. Где показано
Стартовое меню, «Расширенные настройки» (экран правил игры), группа «Поведение ИИ» (`RULE_GROUP_AI_BEHAVIOR`), рядом с правилом Казуальности. Правило действует на всю партию, меняется только до старта [uncertain: смена посреди партии].

## 3. Обязательное правило путей страны
У **каждой проработанной страны с несколькими путями развития** есть правило игры выбора пути (правило автора, пункт 11; опции придуманы).

- Идентификатор: `ktits_<tag>_paths` (`<tag>` — тег страны строчными); локализация `KTITS_RULE_<TAG>_PATHS`, опции `KTITS_RULE_OPT_<TAG>_PATHS_<ОПЦИЯ>` и `..._DESC`. Название по образцу `KTITS_RULE_OPT_*` существующих правил.
- Устройство — как у ванильных правил путей (`SOV_ai_behavior` в `common/game_rules/00_game_rules.txt`: `DEFAULT`, `HISTORICAL`, затем по одной опции на каждый путь страны: «левая оппозиция», «правая оппозиция» и т. д.). Опции у нас:

| Опция | Смысл |
|---|---|
| `DEFAULT` («ИИ выбирает по весам») | ИИ выбирает путь по весам из документа механик страны |
| `<ПУТЬ>` (по одной на каждый путь страны, название пути как в игре) | ИИ-страна всегда идёт по этому пути, веса игнорируются |
| `HISTORICAL` (только если у страны есть «исторический» путь по лору) | путь, заданный лором; единственная опция, не отключающая достижения (как в ваниле) |

- Применяется **только к ИИ**: игрок всегда выбирает путь сам, фокусами. Правило не блокирует фокусы игрока. Опции `PLAYER` нет (решено автором: «как в ванильном меню»).
- Взаимодействие с весами: `DEFAULT` оставляет веса ИИ как есть; опция пути обходит их (ИИ получает вес 0 всем фокусам выбора, кроме нужного, и большой вес нужному). Подпуть выбирается отдельной опцией, если это самостоятельный путь (как «Нейтралитет» и «Великая Казуалия»).
- Опции, кроме `DEFAULT` (и `HISTORICAL`, если есть), отключают достижения (как у существующего правила).

## 4. Казуалия: `ktits_kaz_paths`
Опции (пути см. `focuses/Kazualia-Focus-Tree.md`, «Пути развития», `mechanics/Kazualia.md`, раздел 5). По образцу ванильного правила СССР (`SOV_ai_behavior`: путь выбирается из списка), по одной опции на путь:

| Опция | Название в меню | ИИ-Казуалия идёт по пути | Достижения |
|---|---|---|---|
| `DEFAULT` | ИИ выбирает по весам | по весам (раздел 5 механик) | да |
| `HISTORICAL` | Исторический (Нейтралитет) | Сохранение казуальности → «Нейтралитет» (исторический путь, по лору) | да |
| `GREAT` | Великая Казуалия | Сохранение казуальности → «Великая Казуалия» | нет |
| `COMM_USSR` | Коммунизм: сотрудничество с СССР | Реформистский путь → Коммунизм → сотрудничество с СССР (в конце выбор из трёх: марионетка СССР / союзник / «Своим умом» (независимость); при `DEFAULT` решает вес, при `COMM_USSR` вес по умолчанию) | нет |
| `COMM_CASUAL` | Казуальный коммунизм | Реформистский путь → Коммунизм → «Казуальный коммунизм» (без Вечного нейтралитета, отношения с СССР ухудшены) | нет |
| `DEM_SOVEREIGN` | Суверенная демократия | Реформистский путь → Демократия → «Суверенная демократия» (договор о зонтиках, клерки остаются) | нет |
| `DEM_BRITT` | Демократия на Бриттах | Реформистский путь → Демократия → опора на Бриттов | нет |

Опция пути на каждый конечный путь (лист дерева), как в ваниле у СССР (`SOV_ai_behavior`). Казуальная резервация — не путь, правилом не задаётся. Названия фокусов и структура путей — `focuses/Kazualia-Focus-Tree.md`, «Пути развития».

## 5. Реализация (в игре, не проверено)
- Файл `common/game_rules/ktits_kaz_paths_rules.txt` с правилом `ktits_kaz_paths` пишет `tools/make_casuality.py` (не `make_game_rules.py`: тот же скрипт пишет файл локализации правил); опции `DEFAULT`, `HISTORICAL`, `GREAT`, `COMM_USSR`, `COMM_CASUAL`, `DEM_SOVEREIGN`, `DEM_BRITT`; `has_game_rule = { rule = ktits_kaz_paths option = ... }` в `ai_will_do` фокусов выбора (`tools/make_kazualia.py`).
- Локализации рус./англ. в `ktits_game_rules_l_*.yml` (`tools/make_game_rules.py` или скрипт страны).
- Проверка в `check_mod.py`: у каждой страны с несколькими путями есть правило, у каждой опции есть имя и описание.

- Правило влияет только на `ai_will_do` 12 фокусов выбора пути (`sleep`, `reform`, `n_root`, `g_root`, `red`, `hum`, `c_help`, `c_lazy`, `r_free`, `b_friends`, `r_club`, `c_cell`).
