# Проверка механики «Казуальность»: команды

Механика: `global_mechanics/Casuality-Mechanic.md`. Ничего из этого ещё не проверено в игре. Команды консоли, помеченные [uncertain], не сверены с 1.19 — если не сработают, пришлите ответ консоли.

## Подготовка
1. Запустить игру с модом `Ktits`, лучше с параметром запуска `-debug` (Steam → Свойства → Параметры запуска). Тогда видны ID событий и ошибки скриптов.
2. Для проверки ИИ: в «Правилах игры» выбрать неисторический фокус (второй прогон — исторический).
3. Консоль: клавиша `~` (или `ё`).
4. После проверки прислать `Documents/Paradox Interactive/Hearts of Iron IV/logs/error.log` и скриншоты.

## Теги стран
| Тег | Страна | Зачем |
|---|---|---|
| `SCU` | Казуалия | шкалы нет; целевое решение «Позвать с болот» |
| `MAK` | Советский Союз | крупная страна (всегда «Борьба») |
| `FAR` | Травинная Федерация | некрупная, образование 0 (рост ×1,5) |

## Базовые команды консоли
| Команда | Что делает |
|---|---|
| `debug` | режим отладки: в подсказках видны переменные и флаги |
| `tag MAK` | играть за страну `MAK` |
| `observe` | режим наблюдателя (все страны под ИИ) |
| `pp 999` | +999 политической власти |
| `event ktits_casuality.30` | вызвать событие у текущей страны |
| `event ktits_casuality.30 FAR` | вызвать событие у страны `FAR` |
| `run имя.txt` | выполнить эффекты из файла (см. ниже) [uncertain: папка файла] |

## Как менять шкалу: команда `run`
В консоли нельзя напрямую задать переменную, поэтому шкалу меняем файлом-скриптом.
- Папка для файлов: `Documents/Paradox Interactive/Hearts of Iron IV/script/` (создать, если нет) [uncertain].
- Файл выполняется в области текущей страны (`tag`).

`cas50.txt` — поставить шкалу 50 (вход в яму):
```
set_variable = { var = ktits_casuality value = 50 }
ktits_casuality_update = yes
```
Аналогично `cas80.txt`, `cas95.txt`, `cas100.txt` (меняется только число). Для сдвига на N: `ktits_casuality_change = { VALUE = 10 }`.

`casmonth.txt` — прогнать ежемесячный пересчёт сразу, без ожидания:
```
ktits_casuality_monthly = yes
```

`caspop30.txt` — популярность Казуальности +30 %:
```
add_popularity = { ideology = casuality popularity = 0.3 }
```

`caswar.txt` — объявить войну Казуалии:
```
declare_war_on = { target = SCU type = annex_everything }
```

`casrap.txt` — включить/снять курс ИИ «Сближение»:
```
set_country_flag = ktits_cas_ai_rapprochement
```
(снять: `clear_country_flag = ktits_cas_ai_rapprochement`)

## Сценарии проверки
Ожидаемое — по `docs/global_mechanics/Casuality-Mechanic.md`. Если результат другой — скриншот + `error.log`.

| № | Что проверяем | Шаги | Ожидаемое |
|---|---|---|---|
| 1 | Решения и шкала | `tag FAR`, `pp 999`, открыть решения | категория «Казуальность», графическая шкала 0 / 100, решения поддержки доступны, борьбы — нет (шкала 0) |
| 2 | Ступени | `run cas50.txt`, затем `cas80`, `cas95` | дух ступени меняется (3 → 4 → 5), шкала на GUI; события `.30` и `.31` приходят по одному разу |
| 3 | Цены от образования | `tag FAR` и `tag AHA`, сравнить цену «Подъём на труд!» | FAR ×1,25 (≈63 ПВ), AHA ×0,75 (≈38 ПВ); цена может обновиться только через месяц |
| 4 | Ежемесячный рост | `tag` соседа Казуалии, `run caspop30.txt`, `run casmonth.txt` | событие `.35`; шкала выросла по формуле (+2 сосед, +3 за 30 %) × образование |
| 5 | «Дома Безделья» | взять решение | шкала +5, популярность +10 % |
| 6 | Война с Казуалией | `run cas80.txt` → потом `cas95.txt`, `run caswar.txt`, `run casmonth.txt` | при 80 духа нет (нужно > 80); при 95 — дух «Зов болот» и событие `.34`; мир или шкала ≤ 80 → дух снимается |
| 7 | «Позвать с болот» | `tag SCU`, `pp 999`, война с этой страной, её шкала > 80 | целевое решение у Казуалии; у цели +10 к шкале и второй дух на 60 дней |
| 8 | Переход | `tag FAR`, `run cas100.txt` | событие `.1`: партия «Казуальность», марионетка `SCU`; соседям — `.32` |
| 9 | Капитуляция | довести страну до капитуляции, затем `run cas100.txt` | перехода нет; после выхода из капитуляции — переход в ближайший месяц |
| 10 | Сюзерен | `tag KAN`, `run cas95.txt`; `tag TEZ`, `run cas100.txt` | `KAN` (шкала > 80) — марионетка `SCU`; остальные марионетки независимы, им `.33` |
| 11 | Распад | `tag MAK`, `run cas100.txt` | части `Kxx` из `countries/Splits.md` выделены и стали марионетками `SCU` |
| 12 | ИИ | неисторический фокус, `observe`, ускорить на 1–2 года | у некоторых некрупных стран флаг `ktits_cas_ai_rapprochement` (видно в `debug`), они берут решения поддержки; крупные — только борьба |
| 13 | ИИ, исторический | исторический фокус, тот же прогон | флага ни у кого нет |
