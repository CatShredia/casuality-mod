# Проверка механики «Казуальность»: команды

Механика: `global_mechanics/Casuality-Mechanic.md`. Ничего из этого ещё не проверено в игре. Команды консоли, помеченные [uncertain], не сверены с 1.19 — если не сработают, пришлите ответ консоли.

## Подготовка
1. Запустить игру с модом `Ktits`, лучше с параметром запуска `-debug` (Steam → Свойства → Параметры запуска). Тогда видны ID событий и ошибки скриптов.
2. Для проверки ИИ: в «Правилах игры» выбрать неисторический фокус (второй прогон — исторический).
3. Консоль: клавиша `~` (или `ё`).

|---|---|---|
| `SCU` | Казуалия | шкалы нет; целевое решение «Позвать с болот» |

## Как менять шкалу: команда `run`
В консоли нельзя напрямую задать переменную, поэтому шкалу меняем файлом-скриптом.
- Папка для файлов: `Documents/Paradox Interactive/Hearts of Iron IV/script/` (создать, если нет) [uncertain].
- Файл выполняется в области текущей страны (`tag`).

`cas50.txt` — поставить шкалу 50 (вход в яму):
```
set_variable = { var = ktits_casuality value = 50 }
ktits_casuality_update = yes
```
Аналогично `cas80.txt`, `cas95.txt`, `cas100.txt` (меняется только число). Для сдвига на N: `ktits_casuality_change = { VALUE = 10 }`.

`casmonth.txt` — прогнать ежемесячный пересчёт сразу, без ожидания:
```
ktits_casuality_monthly = yes
```

`caspop30.txt` — популярность Казуальности +30 %:
```
add_popularity = { ideology = casuality popularity = 0.3 }
```

`caswar.txt` — объявить войну Казуалии:
```
declare_war_on = { target = SCU type = annex_everything }
```

`casrap.txt` — включить/снять курс ИИ «Сближение»:
```
set_country_flag = ktits_cas_ai_rapprochement
```
(снять: `clear_country_flag = ktits_cas_ai_rapprochement`)

## Специалисты (образование)
Файлы кладутся туда же, что и остальные (см. «Команда `run`»). Счётчики в тысячах; после любого изменения нужен `ktits_education_update`.

`spec60.txt` — наших 60 (уровень 3 «Развивающееся общество»):
```
set_variable = { var = ktits_spec_own value = 60 }
ktits_education_update = yes
```
Аналогично 0 / 10 / 30 / 100 / 150 для уровней 0–5; 29 → 1, 30 → 2 (границы).

`specfor.txt` — иностранных 20:
```
set_variable = { var = ktits_spec_foreign value = 20 }
ktits_education_update = yes
```

`specmonth.txt` — прогнать месяц сразу (переход иностранных в наших, болото, институты):
```
ktits_education_monthly = yes
```

`impfocus.txt` — открыть решения привлечения без прохождения фокуса (они требуют «Импорт умов»; награда фокуса выдастся) [uncertain: `complete_national_focus` из консоли не проверен; запасной вариант — пройти фокус обычным способом]:
```
complete_national_focus = ktits_edu_imp
```

`specflags.txt` — проверить флаги фокусов без прохождения:
```
set_country_flag = ktits_edu_f_mentor
set_country_flag = ktits_edu_f_inst
set_country_flag = ktits_edu_f_self
set_country_flag = ktits_edu_f_import
```

### Договор о сотрудничестве и шкала науки
Условия: фокус «Импорт умов» (`impfocus.txt`), крупная страна, цель с образованием не ниже 2. Целью удобно брать другую крупную страну; при проверке за вторую сторону — консоль `tag <ТЕГ>`.

1. **Название.** В категории «Образование: развитие» решение называется «Договор о сотрудничестве с <страна>» (у каждой цели своё имя).
2. **Отказ → блок 365 дней только для пары.** Предложить договор стране A, в событии за A выбрать «Отказать». Решение для A исчезает из списка целей (или недоступно) на 365 дней; другая страна B по-прежнему доступна. Проверить, что B может предложить договор A (`tag B`): для неё блока нет. Через 365 дней (`days` не промотать, можно проверить сменой даты командой `date`/ждать) A снова доступна. ПВ при отказе не возвращаются.
3. **Согласие → дух.** Согласиться за A: обе страны получили дух «Научное сотрудничество: <партнёр>» (панель национальных духов). У отправителя пришло событие «Договор подписан». Повторно предложить A договор нельзя (флаг `done`).
4. **Ежемесячно +2 / +1.** Узнать значение: `specmonth.txt` (`ktits_education_monthly = yes`) на обеих сторонах, смотреть «Иностранные специалисты» в описании категории. Инициатор +2 (к обычному переходу 5 % в наших), принявшая сторона +1. Несколько договоров: суммируются (+2 за каждый).
5. **Война снимает дух.** Объявить войну партнёру (`declare_war_on` или через игру) и прогнать `specmonth.txt`: дух снят с обеих сторон; после войны договор можно заключить заново. То же для исчезнувшей страны и марионетки Казуалии.
6. **Казуалия.** Её специалисты всегда 0, цели-марионетки недоступны, духов у них нет.
7. **Шкала.** Над решениями «Образование: развитие» видна шкала из 20 делений. Проверить: `spec0.txt` (own = 0) шкала пуста, подпись «Уровень: Необразованное стадо → Крестьянское образование. Наших специалистов: 0 из 10 тыс.»; own = 5 из диапазона 0–10 — 10 делений серо-голубых по четвертям; own = 15 при пороге 10–30 — 25 % (5 делений, серые); own = 29 — почти полная; own = 150 — все 20 делений, цвета четвертями серый / голубой / синий / золотой, подпись «Общество Будущего: высший уровень». Шкала должна обновляться после `ktits_education_update = yes`. Если подпись выглядит как текст `[GetKtitsEduBar]`, значит `defined_text` не сработал в этом GUI.
