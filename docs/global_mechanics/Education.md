# Механика «Образованность населения»

**Кратко.** У каждой страны (кроме Фигарии и Ледышки) есть национальный дух уровня образованности. Уровень влияет на науку, строительство и пополнение армии, а также на Казуальность.

## Источники
- Скрипт: `tools/make_education.py` (шаг `education` в `post_export.py`).
- **Из лора** (`lore/Contries-Description.md`): шкала из 6 уровней и уровни стран, названных в лоре.
- **Придумано** (`lore/Invented-Lore.md`, раздел «Образованность населения»): модификаторы уровней и уровни остальных стран.

## Уровни
Национальные духи `ktits_edu_0`…`ktits_edu_5`. Модификаторы придуманы.

| Уровень | Название | Исследования | Строительство | Пополнение (`conscription_factor`) |
|---|---|---|---|---|
| 0 | Необразованное стадо | −20 % | −10 % | +10 % |
| 1 | Крестьянское образование | −10 % | −5 % | +5 % |
| 2 | Образованная элита | — | — | — |
| 3 | Развивающееся общество | +7 % | +5 % | −3 % |
| 4 | Образованное общество | +15 % | +10 % | −6 % |
| 5 | Общество Будущего | +25 % | +15 % | −10 % |

Уровни стран — таблица стран в `lore/Lore-Overview.md` и `lore/Invented-Lore.md`.

## Связь с Казуальностью
Подробно — `global_mechanics/Casuality-Mechanic.md`.
- Множитель ежемесячного роста шкалы: от ×1,5 (уровень 0) до ×0,5 (уровень 5).
- Цена решений борьбы: −25 % при уровнях 4–5, +25 % при уровнях 0–1.
- Шанс ИИ перейти на курс «Сближение»: +2 % при уровнях 0–1, −2 % при уровнях 4–5.
- Марионетки Казуалии получают уровень 0; после выхода из марионеток уровень не восстанавливается.

## Не сделано
- Повышение уровня решениями и фокусами.
- Тямовский рейх: «образованы только мужчины» (лор) механикой не отражено.

## Как заменить
`LEVELS`, `LORE_LEVEL`, `INVENTED_LEVEL` в `tools/make_education.py`, затем `python tools/post_export.py --no-zip`.
