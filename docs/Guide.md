# Путеводитель по документам

Главный документ лора — `lore/Contries-Description.md`: при расхождениях прав он. Всё придуманное автоматически собрано в `lore/Invented-Lore.md` (нужна проверка автором).

## `lore/` — лор мира
| Файл | Что внутри |
|---|---|
| `Contries-Description.md` | главный документ лора: страны, правители, механики (CRLF) |
| `Lore-Overview.md` | сводный обзор лора: мир, глобальные механики, идеологии, таблицы стран |
| `Invented-Lore.md` | всё, что придумано без автора, по механикам и скриптам |

## `countries/` — страны
| Файл | Что внутри |
|---|---|
| `Country-Template.md` | шаблон описания страны и чек-лист |
| `Big-Countries.md` | крупные страны (больше 15 штатов) и их части |
| `Splits.md` | выделяемые государства `K01`–`K35`: названия, штаты, правила выделения |

## `map/` — игровая карта
| Файл | Что внутри |
|---|---|
| `Geography.md` | география: материк, рельеф, реки, расположение стран (выписка из лора, менять вместе с ним) |
| `Map-Sketch.svg` | схематичная карта (≈97 км² на единицу SVG); источник для `tools/export_rp_inputs.py` |
| `Map-Sketch-legacy.svg` | старая версия схемы, не трогать |
| `Climate-Plan.svg` | план климатических зон |

### `map/build/` — сборка карты (RandomParadox и скрипты)
| Файл | Что внутри |
|---|---|
| `Map-Build-Plan.md` | план сборки первоначальной карты |
| `Video-RandomParadox-Notes.md` | конспект видео по RandomParadox |
| `RandomParadox-Guide.md` | руководство по программе |
| `RP-Stages.md` | сборка по этапам: файлы для загрузки и проверка каждого этапа |
| `RP-Tabs-Quick.md` | краткая шпаргалка по вкладкам программы |
| `map-fix.md` | список правок после генерации карты |
| `Map-Finish-Plan.md` | доводка карты: таблица скриптов `tools/` и порядок шагов `post_export.py` |

## Где что менять
- География: `lore/Contries-Description.md` + `map/Geography.md` + `map/Map-Sketch.svg` согласованно.
- Новая механика: описание в `global_mechanics/`, придуманное — в `lore/Invented-Lore.md`, скрипт — в `map/build/Map-Finish-Plan.md` (таблица скриптов).
- Старые версии документов (до перестройки папок): `no_commit/legacy_docs/` (не в git).
