# Внутриигровые руководства: как сделать (исследование, 2026-11-20)

**Статус:** только описание. Реализации в игре нет. Тексты страниц — `guides/Guide-Global.md` (для всех стран) и `guides/Guide-Kazualia.md` (для Казуалии).

## Что нашлось в сети
Готового руководства «как сделать внутриигровой гайд» в HOI4 нет; найденное:
- В моде The Fire Rises есть меню гайда, открывающееся в политическом окне страны (закреплённое сообщение в мастерской Steam); автор отказывается переносить его в другие моды, примера кода в открытом доступе нет.
- Скриптовые GUI в вики HOI4 описаны, пример динамического списка с главным окном и контейнером есть в зеркале вики: [зеркало модинг-вики](https://context7.com/drmrmukix/hoi4-modding-page-complete/llms.txt?tokens=10000). Прямые страницы `hoi4.paradoxwikis.com` в этой среде не открылись.
- Общие уроки по моддингу: [тема Paradox «Hearts of Iron IV player resources»](https://forum.paradoxplaza.com/forum/threads/hearts-of-iron-iv-player-resources.1576080) (Iron Workshop, Vezachs); справочник Millennium Dawn по модификаторам и механикам: [code resource](https://millenniumdawn.github.io/Millennium-Dawn/dev-resources/code-resource).
- Ничего о собственных «обучающих окнах» (tutorial) для модов: в ванили есть триггер `is_tutorial` (проверка, активно ли обучение), а папки `common/tutorials` и эффекта показа обучения в игре нет.

## Что видно в самой игре (установка 1.19)
- В ваниле 20 скриптовых GUI в `common/scripted_guis/`, все с `context_type = decision_category`: окно встроено в категорию решений (так же сделаны наши шкалы). Другие контексты в ванильных файлах не встретились.
- Тексты с цветом и подстановкой переменных работают: `§Y…§!`, `[?переменная]`, `[GetКлюч]` (scripted localisation); у нас такое уже используется (шкалы, описания категорий).
- Документация движка: `documentation/script_concept_documentation.md` (привязываемая локализация) и `loc_formatter_documentation.md` (форматирование).

## Варианты реализации
| Вариант | Как | Плюсы | Минусы |
|---|---|---|---|
| А. Категория «Руководство» | Категория решений, видимая всем (для Казуалии вторая — её руководство); тема = решение, текст страницы в описании решения; «нажать» = открыть страницу событием | родной формат, только локализация, текст всегда под рукой | описание решения — подсказка: длинный текст неудобен |
| Б. События-страницы | Решение запускает событие `ktits_guide.N` с длинным описанием и кнопками «Дальше», «Назад», «Закрыть» (страницы = цепочка событий) | длинный текст с картинкой, проверенный в нашем моде формат (стартовые события) | одна страница = одно событие: десятки событий; окно блокирует игру, пока не закрыто |
| В. Скриптовый GUI | В категории «Руководство» окно (`scripted_gui`, контекст `decision_category`) с текстовым полем и кнопками страниц; номер страницы в переменной, текст по ключу локализации `ktits_guide_<раздел>_<страница>` | одно окно, листание, ссылки на разделы | своя вёрстка `.gui`, в игре не проверена; размер текстового поля, прокрутка |
| Г. Руководство вне игры | `docs/guides/*.md` или PDF | уже есть | не в игре |

**Рекомендация (обновлена):** вариант Д (меню в политическом окне) как основной вид, запасной — А+Б (категория «Руководство» и события-страницы), если Д не заработает.

(Прежняя запись: А+Б.) Категория «Руководство» с решениями-темами (всегда видимы, бесплатны, без перезарядки); решение открывает первую страницу события-страницы; страницы листаются кнопками. Позже при желании заменить окно событий на скриптовый GUI (вариант В), тексты страниц остаются теми же (ключи локализации не меняются).

## Вариант Д: меню в политическом окне, как в The Fire Rises (найдено в игре, 2026-11-20)
Кнопка гайда в политическом окне страны (клавиша Q) делается штатным скриптовым GUI. Официальная документация лежит в игре: `common/scripted_guis/_documentation.md`. Что в ней важно:
- Контексты (`context_type`): `player_context`, `selected_country_context`, `selected_state_context`, `diplomacy_target_context`, `decision_category`, `diplomatic_action`, `national_focus_context`, `country_mapicon`, `state_mapicon`.
- `parent_window_token` крепит окно к уже существующему окну: `top_bar`, `decision_tab`, `technology_tab`, `trade_tab`, `construction_tab`, `production_tab`, `deployment_tab`, `logistics_tab`, `diplomacy_tab`, `national_focus`, **`politics_tab`**, `selected_country_view`; можно прицепить окно к другому скриптовому окну (`parent_scripted_gui`).
- Видимость: `visible = { … }`; кнопки: `effects = { <кнопка>_click = { … } }`, доступность и видимость элементов: `triggers`; смена картинки и позиции: `properties`; списки: `dynamic_lists`; обновление по переменной: `dirty = <переменная>`.
- Ванильные файлы используют только `decision_category`; `player_context` и `politics_tab` в них не применяются, поэтому работоспособность для нашего мода [uncertain: проверить в игре].
Схема меню (придумана):
1. `ktits_guide_button_ui`: `context_type = player_context`, `parent_window_token = politics_tab`, `visible = { ktits_is_kazualia = yes }` или для всех стран, в `interface/ktits_guide.gui` контейнер с одной кнопкой «Руководство» (спрайт и подсказка); по нажатию `set_variable = { ktits_guide_open = 1 }`.
2. `ktits_guide_window_ui`: `parent_scripted_gui = ktits_guide_button_ui`, окно с заголовком, списком разделов (кнопки), текстовым полем страницы и кнопками «Назад», «Дальше», «Закрыть»; `visible = { check_variable = { ktits_guide_open = 1 } }`.
3. Страницы: переменные `ktits_guide_section`, `ktits_guide_page`; текст поля — scripted localisation `[GetKtitsGuideText]` (`defined_text`, по одной ветке на раздел и страницу, как у нашего `GetKtitsAllyDesc`), `dirty = ktits_guide_page` обновляет окно при листании.
4. Тексты — те же `guides/Guide-Global.md` и `guides/Guide-Kazualia.md`: ключи `ktits_guide_<g|k>_<N>`.
5. Для ИИ окно отключается: `ai_enabled = { always = no }`.
Положение кнопки: окно политики 550 px шириной (`interface/countrypoliticsview.gui`), точное место для кнопки подбирается по картинке; сначала самый простой вариант: кнопка рядом с заголовком окна.

## Правила для текстов
- Тексты страниц лежат только в локализации (`ktits_guide_<раздел>_<страница>`), в окне подставляются актуальные числа переменных (`[?ktits_casuality]`, `[?ktits_kaz_inner]`).
- Одна страница не длиннее ~900 знаков (предположение, лимит не проверен [uncertain]).
- Тексты фактические (числа из `global_mechanics/`, `mechanics/`), не лорные: коротко, что делает механика, как ею управлять, чем рискуешь. Отдельная строка в конце страницы: «Где в игре» (категория, фокус).
- Руководство Казуалии показывается только Казуалии (`ktits_is_kazualia`), общее — всем странам (кроме перешедших в Казуальность? решение автора).
- Новую механику — сначала страницу в руководстве (одновременно с документом механики), затем реализация.
